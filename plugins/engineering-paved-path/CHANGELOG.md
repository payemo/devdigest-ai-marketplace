## [1.0.0] - 2026-10-13

### Added
- `react-best-practices` — modern React conventions and anti-pattern catalog.
- `next-best-practices` — Next.js file conventions, RSC boundaries, data patterns, metadata, bundling (not user-invocable; loads on demand).
- `fastify-best-practices` — Fastify routes, plugins, hooks, schemas, errors, testing, deployment.
- `onion-architecture` — layering rules for a TypeScript/Node backend, written project-neutral: the layer map is an input, examples use a fictional `orders` service.
- `react-testing-library` — user-flow-oriented React Testing Library + Vitest guide with MSW.
- `security` — OWASP Top 10:2025 guidance with checklists, unsafe/safe code pairs and references.
